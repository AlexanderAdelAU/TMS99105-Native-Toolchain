FILESTAT / TEXT EDITOR -- native SBC build sequence
================================================

The commands below show the application build using the existing SBC tools.
Generated files are shown explicitly so the resident/overlay relationship is
visible.

1. Compile the executable entry module normally:

   SMALLC99 FILESTAT

2. Compile resident helper modules and overlay modules with -M:

   SMALLC99 FILEIO   -M
   SMALLC99 FILEDATA -M
   SMALLC99 TERMIO   -M
   SMALLC99 EDITBUF  -M
   SMALLC99 VIEWCTL  -M
   SMALLC99 EDITCTL  -M
   SMALLC99 EDITMENU -M
   SMALLC99 OVL_WORD -M
   SMALLC99 OVL_CHAR -M
   SMALLC99 OVL_RPT  -M
   SMALLC99 OVL_VIEW -M
   SMALLC99 OVL_EDIT -M
   SMALLC99 OVL_PASTE -M      (the SBC file is OVL_PAST: names are 8.3)
   SMALLC99 OVL_NAMEIO -M     (the SBC file is OVL_NAME)

3. Assemble the generated A99 modules:

   R99 FILESTAT
   R99 FILEIO
   R99 FILEDATA
   R99 TERMIO
   R99 EDITBUF
   R99 VIEWCTL
   R99 EDITCTL
   R99 EDITMENU
   R99 OVL_WORD
   R99 OVL_CHAR
   R99 OVL_RPT
   R99 OVL_VIEW
   R99 OVL_EDIT
   R99 OVL_PASTE
   R99 OVL_NAMEIO
   R99 EBMAP      (hand-written resident bank mapper)
   R99 CONRX      (hand-written interrupt-driven console receive)

4. Assemble the resident overlay runtime.  It includes no generated
   file: OVLMGR refers to the table with EXT OVL_TABLE.

   R99 OVLMGR
   R99 OVCALL

5. Link with the overlay map.  LINK99 reads OVLMAP.TXT, places each
   overlay on its page, and builds OVL_TABLE and the resident thunks
   itself (OVLGLUE.R99).  The overlays need no -P.
   make_SBC_FileEdit99.ps1 shows the exact command.

   The native SBC LINK99 reads the same map (-Y) and gives the same
   FILEEDIT.EXE as the Windows link99 from the same arguments.  The
   command line is too long for the shell, so the arguments go in a
   file: LINK99 @FILEEDIT.LNK.  link99\tests\fileedit has a FILEEDIT.LNK
   that takes the resident modules from a library, and packs everything
   into one FE.PAK for XMODEM (UNPACK FE on the SBC).  This link has
   been run on the board (17 November 2026).  DREL -i and
   OVLADDR.INC/OVLTABLE.INC are no longer part of the build.

Build-mode distinction:

   FILESTAT        normal mode -> executable startup is emitted
   all other C     -M          -> module output, no startup branch

Hardware smoke tests:

   FILESTAT SAMPLE.TXT /E     Step 6 editor with Open/New/Save As
   FILESTAT /E                Step 6 editor with no initial document
   FILESTAT SAMPLE.TXT /V     direct Tera Term viewer
   FILESTAT SAMPLE.TXT        original analyser
   FILESTAT SAMPLE.TXT /L     original list + analyser
