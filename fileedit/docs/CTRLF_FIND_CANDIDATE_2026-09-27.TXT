FILEEDIT99 Ctrl-F Find candidate — 27 September 2026

Base

SBC_FileEdit99_CLI_SE_HARDWARE_VALIDATED_2026-09-27

Function
--------
Ctrl-F while editing opens a Find prompt on row 24.

  * Search is case-sensitive.
  * Maximum pattern length is 32 printable characters.
  * Backspace/Delete edits the pattern.
  * Ctrl-U clears the pattern.
  * Esc cancels without moving the cursor.
  * Enter searches forward from the current cursor position, inclusive.
  * Search does not wrap at EOF.
  * A match moves the cursor to the first matching character and adjusts the
    vertical and horizontal viewport so the match is visible.
  * Not found displays "Not found - press any key", rings the bell, and leaves
    the document/cursor unchanged.
  * No search string is retained between Ctrl-F operations in this first version.

Architecture
------------
OVL_EDIT only recognises Ctrl-F and returns edflag=4.  Resident EDITCTL maps
OVL_VIEW for one operation.  OVL_VIEW owns the one-shot prompt/search and then
returns to EDITCTL, which performs a normal full redraw before accepting the
next edit key.

This keeps all persistent editor-buffer state unchanged and avoids expanding
OVL_EDIT beyond its single-page budget.
