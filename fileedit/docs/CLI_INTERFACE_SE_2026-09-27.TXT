New public command line:
  FILEEDIT
      Displays usage.

  FILEEDIT <filename> /S
      Displays FILESTAT analysis/statistics.

  FILEEDIT <filename> /E
      Opens the file in the editor.

A filename without /S or /E displays usage.  Unsupported or extra arguments
also display usage.  The old public /L, /V, filename-less /E, and /I command
paths were removed from the command-line driver.  Viewer and statistics
functions used internally by the editor remain unchanged.
