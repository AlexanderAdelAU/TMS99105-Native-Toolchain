STATUS

Wording-only candidate based on the hardware-tested Ctrl-V Paste Fix build.
No paste, editor-buffer, find, file-I/O or input-queue logic was changed.

USER INTERFACE CHANGE
---------------------
The footer no longer says '^V Paste', because Ctrl-V cannot directly access
the Windows clipboard.  Ctrl-V arms FILEEDIT to receive terminal paste data.

Footer:
  Home End PgUp/Dn ^F Find ^V PasteMode ^O Save ^X Menu

The footer is 53 characters long, exactly the same width as the corrected
hardware-tested footer, so it remains within the safe terminal width.

Paste-mode prompt:
  PASTE MODE - use Tera Term Edit>Paste, Esc finish

OPERATION
---------
1. Press Ctrl-V in FILEEDIT to enter Paste Mode.
2. In Tera Term choose Edit -> Paste and confirm/send the clipboard text.
3. When transmission is complete, press Esc.
4. FILEEDIT performs one full redraw and leaves the cursor after the pasted
   text.
